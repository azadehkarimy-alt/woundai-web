# قرارداد افزونه استنتاج پژوهشی WoundAI v30.4

## وضعیت پیش‌فرض
هیچ مدل یا وزن آموزشی در بسته توزیع نمی‌شود. بدون افزونه معتبر:
- `GET /health` مقدار `model_loaded=false` برمی‌گرداند.
- `POST /v1/tissue/analyze` با HTTP 503 رد می‌شود.
- هیچ ماسک یا پیش‌بینی ساختگی تولید نمی‌شود.

## قرارداد افزونه سرور
افزونه باید یک ماژول Python مورداعتماد باشد که مدیر سرور آن را نصب کرده و نام آن را در متغیر محیطی `WOUNDAI_INFERENCE_MODULE` قرار دهد. مسیر فایل checkpoint و SHA-256 مورد انتظار آن نیز باید از طریق `WOUNDAI_CHECKPOINT_PATH` و `WOUNDAI_CHECKPOINT_SHA256` تنظیم شوند. خود adapter فایل را می‌خواند و checksum را مقایسه می‌کند؛ صرف اعلام یک مقدار boolean از طرف افزونه کافی نیست. ماژول باید دو تابع داشته باشد:

```python
def model_status() -> dict:
    return {
        "runtime_ready": True,
        "checkpoint_configured": True,
        "checkpoint_exists": True,
        "model_name": "نام دقیق مدل",
        "model_version": "نسخه ثابت مدل",
        "model_card_id": "شناسه/نشانی مستندات مدل",
        "training_domain": "جمعیت و نوع زخم داده آموزشی",
        "license": "شناسه مجوز کد و وزن"
    }

def predict(image_bytes: bytes) -> dict:
    return {
        "mask_png": b"... PNG 8-bit grayscale ...",
        "class_confidence": {
            "granulation": 0.0,
            "slough": 0.0,
            "necrosis": 0.0,
            "other": 0.0,
            "unclassified": 0.0
        },
        "quality_flags": []
    }
```

مقادیر بالا نمونه قرارداد هستند، نه نتیجه مدل. adapter فقط وقتی checkpoint را تأیید می‌کند که فایل موجود باشد و SHA-256 محاسبه‌شده با مقدار تنظیم‌شده دقیقاً برابر شود. این کنترل یکپارچگی فایل است و به‌تنهایی منشأ، مجوز یا کیفیت مدل را تأیید نمی‌کند.

## قرارداد ماسک
ماسک باید PNG، تک‌کاناله ۸ بیتی و دقیقاً هم‌اندازه تصویر ورودی باشد. کدهای مجاز:
- `0`: unclassified
- `1`: granulation
- `2`: slough
- `3`: necrosis
- `4`: other
- `255`: خارج از ناحیه زخم

کدهای دیگر، ابعاد متفاوت، فایل خراب، ماسک خالی و خروجی بزرگ‌تر از سقف تعیین‌شده رد می‌شوند. این قرارداد هیچ روش تشخیصی یا آستانه درمانی تعریف نمی‌کند.

## قرارداد confidence
مقادیر confidence باید بین ۰ و ۱ باشند و فقط برای کلاس‌های شناخته‌شده گزارش شوند. اگر مدل confidence معتبر تولید نمی‌کند، مقدار را حذف کند؛ مقدار ساختگی یا تبدیل دلخواه نکنید. confidence خام الزاماً احتمال کالیبره‌شده نیست.

## محدودیت ایمنی
API خروجی را همواره پژوهشی علامت‌گذاری می‌کند:
- `ai_generated=true`
- `research_only=true`
- `clinical_use=false`
- `diagnosis=null`

خروجی نباید تشخیص، شدت قطعی، توصیه درمان، تعیین فوریت یا پیش‌بینی ترمیم تولید کند. درمانگر باید تصویر اصلی و ماسک را بازبینی کند. این بازبینی نیز به‌تنهایی اعتبارسنجی مدل محسوب نمی‌شود.
