# ثبت منابع راهنمای بالینی

فایل `guideline-registry.json` فهرست نسخه‌ها و دامنه کاربرد منابعی است که موتور پیشنهاددهنده به آن‌ها ارجاع می‌دهد.

- IWII ویرایش چهارم ۲۰۲۶: ارزیابی/مدیریت عفونت زخم.
- NPIAP/EPUAP/PPPIA ویرایش چهارم ۲۰۲۶: آسیب فشاری.
- IWGDF/IDSA ۲۰۲۳: عفونت پای دیابتی.
- IWGDF ۲۰۲۳: offloading زخم پای دیابتی.
- NICE NG152: stewardship آنتی‌میکروبی در زخم عفونی ساق.

این registry نسخه‌بندی و تاریخ بازبینی را ثبت می‌کند اما به‌صورت خودکار وب را پایش نمی‌کند. مسئول علمی پروژه باید نسخه‌ها و اصلاحیه‌ها را دوره‌ای بازبینی و پس از تأیید، قواعد نرم‌افزار را به‌روزرسانی کند. بازنشر متن کامل راهنماها بدون رعایت مجوز/حق نشر مجاز نیست؛ نرم‌افزار فقط خلاصه عملیاتی و ارجاع به منبع را نمایش می‌دهد.
