# WoundAI Web Prototype v0.2

نسخه بازطراحی‌شده برای نمایش موبایل و استفاده با گوشی اندرویدی.

## تغییرات v0.2
- طراحی واکنش‌گرا با اولویت موبایل، دکمه‌ها و فیلدهای بزرگ‌تر
- نوار ناوبری قابل پیمایش در موبایل
- کارت‌ها، فرم‌ها، داشبورد و پنل اندازه‌گیری با خوانایی بهتر
- کاهش وابستگی به فونت آنلاین با fallback مناسب
- نگهداری امکانات قبلی ثبت پرونده آزمایشی، بارگذاری تصویر، کالیبراسیون، ترسیم دستی مرز و محاسبه مساحت

## اجرای درست روی گوشی
بازکردن مستقیم index.html از مسیر content:// فقط برای پیش‌نمایش محدود است و ممکن است فایل‌های CSS/JS یا قابلیت‌های PWA را کامل اجرا نکند.
برای استفاده صحیح باید کل محتویات این پوشه (خود فایل‌ها و پوشه assets) روی یک هاست HTTPS استاتیک منتشر شود. سپس لینک HTTPS را در Chrome باز کنید و از منوی Chrome گزینه Add to Home screen / Install app را بزنید.

## محدودیت‌ها
این نسخه تشخیص پزشکی خودکار ندارد. اندازه‌گیری نیازمند کالیبراسیون و ترسیم/بازبینی دستی است. داده‌ها فقط در همان مرورگر ذخیره می‌شوند و برای اطلاعات واقعی بیمار یا استفاده بالینی تأیید نشده‌اند. از تصاویر و اطلاعات شناسایی‌کننده بیماران استفاده نکنید.
