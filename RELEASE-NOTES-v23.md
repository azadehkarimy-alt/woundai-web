# WoundAI Version 23 — Research prototype

- Separate clinical screening alerts and appointment follow-up dashboards.
- Appointment dates, reminders, completion, cancellation and rescheduling.
- Rule-based explainable alerts for selected clinical fields and wound-area increases; **not validated clinical AI**.
- Persian date formatting uses the Persian calendar; existing date inputs remain native Gregorian controls and are NOT a complete Jalali date-picker implementation.
- Alerts are evaluated when the app is opened; no push notifications.
- Appointments are saved with the existing local record and included in JSON export/import.
- No clinical validation, security audit, or real-device testing completed. Do not use with real patient data.
