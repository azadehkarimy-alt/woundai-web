# WoundAI Version 20

## Scope of this update
- Replaced the simplified front/back body diagrams in the wound-registration modal with the user-approved, more realistic male anatomical illustration.
- Added touch-friendly selectable anatomical markers on both front and back views.
- Selecting a marker updates the selected-region label and the wound-site field.
- Kept the existing text-based region buttons available as an alternative.
- Updated displayed version labels and service-worker cache to Version 20.

## Preserved
- Existing branding, logo, app icon, color palette, patient records, clinical forms, English UI content, and other modules were not intentionally changed.

## Validation
- JavaScript syntax checks and project smoke tests.
- ZIP integrity and required asset checks.
- Physical-device interaction and visual alignment should still be verified after deployment.
