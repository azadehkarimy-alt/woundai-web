# WoundAI V25 — Mobile Patient List & White App Icon

- Preserves the full V24 application and data formats.
- Replaces installed PWA launcher icons with the approved WoundAI logo composited on white.
- Sets the installed app short name to `WoundAI V25` and updates in-app version labels.
- Forces a single-column patient list on phone/tablet widths (<=1100px).
- Makes patient-card action buttons wrap in a two-column grid, or one column on very narrow screens.
- Updates service worker cache to v25.

Note: Home-screen labels are ultimately controlled by the Android launcher. Existing installations may need an icon refresh or reinstall; back up local patient data first.
